# research/ (local only)

Reverse-engineering workspace. **Everything in this folder is git-ignored except this file.**

What goes here: Ghidra projects, notes containing disassembly or pseudocode of the game, the knowledge base (`kb/`),
import lists, traces, clones of reference projects for evaluation, and the local MCP server configuration.

General knowledge without game code or data is moved to `docs/`.
Symbol maps (name → address) go to `games/<id>/regions/<id>/symbols.toml`.
